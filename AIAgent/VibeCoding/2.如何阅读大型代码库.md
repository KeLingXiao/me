# 如何阅读大型代码库

快速了解一个项目最重要的途径就是 架构设计文档, 最后摸清楚架构就对你所感兴趣的 模块单独询问学习即可(数据库/功能 等模块)(从 设计方案/实现方式/设计方案 这几种路径入手)

大型代码库我们
1. 阅读 codex 代码:
仔细阅读 codex 代码 撰写一份详细架构分析文档, 如需图标可以调用 mermaid chart, 文档放在 当前目录的 codex-arch-by-codex.md
2. 阅读 codex 的 history
查看 repo 中所有 commit history 梳理其代码变更脉络 必要时辅以 mermaid chart 写入 codex-arch-by-codex.md
3. 事件循环
帮我熟悉 codex 代码处理事件循环部分详细解读当前用户发起一个查询/任务时候 codex 是如何分解处理该任务并且不断自我迭代 最终完成整个任务 这个过程发生什么 codex 如何决定任务完成还是未完成继续迭代
4. 工具调用
帮我熟悉 codex 代码处理工具调用部分详细解读当codex需要调用工具时 codex 如何选择工具, 处理工具返回结果, 必要时辅以 mermaid chart
5. 记忆管理
帮我熟悉 codex 记忆模块内容, 如何管理记忆, 管理记忆方式 等等, 必要时辅以 mermaid chart
